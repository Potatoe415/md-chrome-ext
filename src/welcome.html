Markdown CoolReader

Markdown files open in Chrome formatted for reading.

Files on your computer

Chrome only lets an extension read files opened from your computer (file://) once you allow it.

  1. Open the details of this extension (button below).
  2. Turn on “Allow access to file URLs”.

Chrome restarts the extension when you change this setting, which closes this page.

Markdown files on websites

Optional: also format .md files that websites send as plain text (for example raw files on GitHub). Chrome asks for access to the sites; only addresses ending in .md are touched.

How to use it

  • Drag a .md file into Chrome, or press Ctrl+O in Chrome and choose it.
  • The panel on the left lists the headings; Ctrl+K searches the text; Aa sets size, width, font and theme.
  • The pencil edits the text on the page; Ctrl+S saves the .md file.
  • Links to other .md files and the images beside the file work as they are.
